刚开始学强化学习（RL）的时候，最难的不是某一个具体算法，而是把整幅图装进脑子里。每个算法好像都在回答一个稍微不一样的问题，而教科书介绍它们的顺序，往往要等你学完了才觉得合理。

这篇文章是我希望自己第一天就能拿到的那张地图，分成三部分：

1. **重要概念**——后面一切的词汇基础。
2. **重要理解**——几个让我真正想通的连接点。
3. **算法版图**——model-based 与 model-free，从 value iteration 一路到 PPO 和 TD3。

先做个非正式的设定：在 RL 中，agent 观测到状态 *s*，按照策略 π 选择动作 *a*，从环境拿到奖励 *r*，然后进入新的状态 *s′*。目标是找到一个策略，使长期的（折扣）奖励之和——也就是**回报（return）**——最大。下面所有内容，都是在把这句话说精确、并且让它可以被学出来。

---

## 一、重要概念

### state transition（状态转移）

**状态转移的随机性来自于环境**：agent 做出动作之后，可能由于环境的随机性导致状态发生变化。但是环境也可能没有随机性，此时就是确定状态转移。

在强化学习中，通常假设状态转移函数**平稳（stationary）**，即转移函数不随时间 *t* 变化。agent 在学习的过程中，世界的规则是不变的。

### Bellman equation（贝尔曼方程）

贝尔曼方程用于**联系不同 state 的 state value 之间的关系**——每个状态自己的 state value 同时依赖于其他状态。

有两个版本要分清：

- **BE**：状态值之间的递归关系。
- **BOE（贝尔曼最优方程）**：最优策略下每个状态值函数的递归关系。换句话说，**贝尔曼最优方程就是在最优策略下的贝尔曼方程**。

两者里面都有折扣因子 **γ**，它**控制模型的近视和远视程度**：γ 小则主要关心眼前的奖励，γ 大则看重长远的未来。

关于 BOE 有两点值得记住：

- **BOE 求解出的状态值唯一，但是 policy 不一定唯一**——不同的策略可能达到同样的最优值。
- **value iteration 和 policy iteration 是两种解法**（详见第三部分）。

### value function（价值函数）

价值函数是 RL 的硬通货，有三个必须分清楚。

**action-value function Q(s, a)。** 它**是条件期望，通过期望消除 t+1 及之后带来的不确定性**。剩下的影响因素主要有三点：

- 当前状态 *s_t*；
- 当前动作 *a_t*；
- **策略**——因为受到策略影响，**因此可以用于评价策略**。

**optimal action-value function Q\*(s, a)。** 可以**理解为先知**。它在 Q 的基础上**排除了策略的影响**（假设从现在起选择最优的策略），因此：

- **可以用于指导智能体的动作**，也就是用来选择 state-action pair；
- **已知 s_t 和 a_t，不论未来采取什么样的策略 π，回报 U_t 的期望不可能超过 Q\***。它就是天花板。

**state value V(s)。** 把 Q(s, a) 中的 **action 求期望从而消除不确定性**，于是它**只依赖于策略和当前状态**。

一个很干净的区分方式：**state value 用于评估 state，action value 用于评估 (s, a) pair**——两者都是加权平均，也就是期望的概念，只是作用在不同的地方。

最后，**求解 action value 有两种方法：BOE，和通过数据求解**。这正好预告了第三部分 model-based 与 model-free 的分野。

### policy（策略）

策略可以从三个角度分类。

**分类 1：确定性 vs. 随机性**

- **deterministic policy**：每个状态对应唯一一个动作。典型代表是 **greedy policy**——选择 action value 最大的 *a*。
- **stochastic policy**：不同 *a* 呈现概率分布。**soft policy** 如 **ε-greedy**，**非最优的动作也可能被采纳**，这是**对 exploitation 和 exploration 的平衡**。
- **确定策略是随机策略的特例：概率全部集中在一个动作上。**

**分类 2：on-policy vs. off-policy**

- **on-policy**：行为策略和目标策略相同。代表算法：SARSA、REINFORCE、A2C。
- **off-policy**：行为策略和目标策略不同。注意**目标策略不能是确定性策略，否则行为策略没有探索性**。off-policy 使用行为策略收集数据填入 **replay buffer** 进行 **experience replay**，用于更新目标策略。

**分类 3：behavior policy vs. target policy**

- **behavior policy**：控制 agent 和 env 交互，用于收集经验（obs, a, r）。关键在于，**在这个过程中策略是没有得到更新的，也因此收集到的经验全部都是过时的旧策略得到的经验**。因此**如果 Q 本身不依赖于策略、只求最优值，则可以使用**——比如 off-policy 的 Q-learning 和 DPG。
- **target policy**：最终希望得到的最优策略，用于控制 agent。

### episode 和 epoch

两个长得像、但属于不同世界的词：

- **episode**：agent 从开始到结束的序列过程。其中观测到的所有的状态、动作、奖励组成 **trajectory**。
- **epoch**：常用于监督学习，用训练数据进行前向计算和反向传播，数据只用一次。

### MDP

**马尔可夫决策过程（MDP）通常指的是四元组 (S, A, p, r)**，其中 S 是状态空间，A 是动作空间，p 是状态转移函数，r 是奖励函数。**有时 MDP 指的是五元组 (S, A, p, r, γ)**，其中 γ 是折扣率。

**Markov property**：**下一个时刻状态仅依赖当前状态和动作，不依赖于过去**。当下就是历史的充分总结。

### bootstrapping（自举）

**"用一个估算去更新同类的估算"**——比如用另一个价值估计来更新当前的价值估计，而不是等真实结果出来。

它的特征是：**方差小，收敛快**（代价是有偏）。**和 MC 的对比恰好相反**——这个对比是比较算法时最有用的一根轴。

### experience replay（经验回放）

经验**存在 replay buffer 中，用于反复训练智能体**。

- **数组保留的数据条数是需要调整的超参**。实践上，**当储存的经验不够多的时候智能体继续与环境发生交互，等到储存到足够数量的经验时才开始更新参数**。
- **随机抽取——经验独立——消除相关性——更好的训练效果。**
- 注意区分两个量：**样本数量取决于现实实验中获得的经验数，而更新次数取决于训练的时候的计算量，前者更重要**。

**prioritized experience replay（优先经验回放）** 更进一步：**经验抽样概率非均匀分布**，并且**根据抽样概率调整学习率，概率大的学习率小**。这样**数据利用率高，但是计算量大，收敛速度比较慢**。

### importance sampling（重要性采样）

重要性采样让你可以用从**另一个**分布中抽到的样本，去估计某个分布下的期望——办法是给每个样本加权。它是把 on-policy 方法变成 off-policy 的数学桥梁，在后面的 A2C 和 PPO 部分会正式登场。

## 二、重要理解

这几条是让我从一堆定义走到一幅图的关键连接。

### RL 随机性的两个来源

1. **动作的随机性**：policy 带来的随机决策。
2. **状态的随机性**：状态转移函数。**虽然 agent 基于 s 的 a 确定下来了，但是由于环境，s′ 仍旧具有不确定性，是一个随机采样**。

那奖励呢？**奖励 r 完全由当下的 s 和 a 决定，但由于状态和动作的随机性，奖励也有不确定性。**

RL 里几乎所有"这里为什么要取期望"的问题，最后都能追溯到这两个来源之一。

### Q-learning VS Sarsa

**核心在于估计的对象是什么表达式，其是否依赖于策略。** Sarsa 估计的是**当前策略下**的 action value（所以必须 on-policy）；Q-learning 直接估计**最优** action value（所以可以 off-policy）。把这个问题记在心里，这两个算法就再也不会混。

### TD error 的总结对比

TD 学习是用一个**信息更充分的预测**去修正原来的预测。

实际上这个 step 怎么理解呢？在 TD 的 D 中，**step 与 T 有关**。**单步的 TD 就是根据一步之后更新的（基于部分事实（奖励）得到的）预测值，跟上一个时间步得到的预测值进行求差，然后进行更新。**

这种 **one-step 可以推广到 n-steps**，也就是说**再往前走 n 步，然后根据那个时候的 discounted return 和余下的 q 进行更新**。而**最终的无穷版本就是 MC，因为 MC 把轨迹从头走到了尾，因此实际上完成了这趟旅途**。

这条谱系上的权衡是：**MC 方差大，收敛速度慢；但是有无偏性。** 单步 TD 则站在另一端（方差小、收敛快，但因自举而有偏）。

### actor-critic 里面的价值网络和 DQN 的对比

它们看起来是同一个网络——都是输入状态、输出动作对应的价值——但估计的东西不同：

**与 DQN 的差别：简单来说就是 DQN 是最优价值函数，因此与特定策略无关，而价值网络得到的是给定策略下的价值，因此非最优。由于以上特性，DQN 可以是 off-policy，而价值网络只能是 on-policy。**

## 三、算法版图

RL 里最干净的一刀：**model-based 和 model-free 之间的区别就是前者有一个确定的模型。**

### model-based

模型已知时，可以直接求解 BOE。

**value iteration（由初始值开始）**，每轮交替：

- **policy update**：对当前的值取 greedy 策略；
- **value update**：这一步是根据"贝尔曼方程"求出的 V_{k+1}，**step number = 1**，没有内层循环。

**policy iteration（由初始策略开始）**，每轮交替：

- **policy evaluation（PE）**：求解当前策略下的状态值。这一步是 **iteration 的嵌套**，原则上要**无穷步直到 V 收敛**。这里有个细节：求解给定策略下的状态值本身是一个 iteration，是根据"贝尔曼方程"求解的；**之所以说"根据"而不是"就是"贝尔曼方程，是因为里面的值不是 state value 而是迭代中的值**。
- **policy improvement**：对求出的值取 greedy，改进策略。

**truncated policy iteration**：只迭代**有限的 j 步**（求状态值这一步），是上述两个方法的**折衷**。value iteration（j = 1）和 policy iteration（j = ∞）成了同一个算法族的两个极端。

### model-free

没有模型？那就从数据里估计。下面分成蒙特卡洛、value-based 和 policy-based 三块。

---

#### 蒙特卡洛 MC（off-line）

核心思想：**MC 可以对期望进行近似**——跑 episode，把观测到的 return 平均起来。

**MC-basic。** 在 **policy iteration 的 PE 这一步直接对 episode 的 return 求平均**。传统的 PE 是通过先求出 V 然后再求 (s, a) 的 action value，**但是此方法直接估计 action value，因为 V →(s, a) 这一步需要 model**。**由于算法起源于 policy iteration 算法，所以收敛性可以保证。**

**MC exploring starts。** 要求 **(s, a) start a episode**，即每个状态-动作对都能作为 episode 的开端。这是一个很强、往往不现实的要求。

**MC ε-greedy。** 三个核心观点：

1. **通过牺牲算法的最优性得到了算法的探索性。**
2. **是前两种算法的平衡**，通过给予非最优 (s, a) 策略权重来满足探索性。**虽然生成的策略可能与 greedy 相同，但是从 V 来看最优性减少**（V 大的时候说明最优性好）。
3. **在 episode 足够长的时候，不需要 (s, a) 为开端也能够保证遍历到每一个状态-动作对，因此可以节省计算。**

实践上：**ε 最初要取较小值，以此保证策略一致性（consistency，即与最优下的策略一致，即使本方法非最优）。**

---

#### value-based learning：时序差分 TD（用 RM 求解，on-line）

**Robbins-Monro（RM）** 是 TD 底下的数学引擎：**不需要 model 求解 solution**。**SGD 是一种特殊的 RM**，而 **GD → BGD → SGD** 是一条随机性递增的链——**每次更新使用的样本数越多，随机性越小，反之则越大**。

TD 有一族变体：

**TD variant 1：估计给定策略下的状态值。** **只能用于 policy evaluation，不能用于估计 action value / optimal policy。** 其中的 **TD error** 里，**差项体现了两个相邻时间帧的差，因此有时序性**。

**TD variant 2：用 RM 求解贝尔曼期望方程** V_π(s) = E[R + γV_π(S′) | S = s]，s ∈ S。同一个算法的另一种理解方式。

**TD variant 3：Sarsa（on-policy）。** 利用 Sarsa 进行 policy evaluation（更新 action value），然后进行 policy improvement。它用到的是五元组 **(s_t, a_t, r_t, s_{t+1}, ã_{t+1})**——名字就是这么来的。**a_{t+1} 依赖于策略，因此 SARSA 也是依赖于当前策略的。** 深度学习版本把表格换成网络：由 **TD target** 定义 **loss function**，再对它求 **gradient** 更新网络。

**TD variant 4：Expected Sarsa。** 把采样得到的下一个动作换成对策略动作分布求期望，target 里的随机性更小。

**TD variant 5：n-step Sarsa（MC + Sarsa）。** 往前走 n 步再自举，是第二部分那条谱系上 MC 和 Sarsa 之间的插值。

每个变体都对应着它隐含求解的那个贝尔曼式方程，**对标 BE 总结对比**是一个非常值得做的练习。

---

#### Q-learning 和 DQN

**Q-learning 标的直接是 action value**（最优的那个），不是某个特定策略下的值。因为目标不依赖策略，所以它**可以是 off-policy 也可以是 on-policy**。

**高估问题。** Q-learning 会系统性地高估，原因有二：

1. **bootstrapping 带来的偏差传播**——虚高的估计被写进下一个 target，误差扩散开来。
2. **max 操作带来的 a 上的非均匀高估**——正是"非均匀"让它对动作选择产生了实际危害。

两种解决方法：

- **使用目标网络的 DQN。** 用一个单独的、缓慢更新的网络来算 target，**选择和求值都用目标网络**。但**目标网络的参数更新和 DQN 本身相关联，因此没有完全切断 bootstrapping**。
- **double Q-learning。** 把两个角色拆开：**第一步的选择用 DQN，第二步的求值用目标网络**。缓解高估的原理是：**上一个方法得到的 a⁻ 是在 w⁻ 参数下能够得到最大 Q 值的动作，然而 a\* 是基于 w 参数得到的动作，不管它是什么，它在 w⁻ 参数下得到的 Q 都不会超过最大值，因此学习到的 y_t 会偏小**——这就是一个内建的、对抗高估的修正。

**DQN 基础。** 表示为 **Q(s, a; w)**，输入状态、输出每个动作对应的值。**由于输入输出限制，只能用于离散动作输出，用于进行决策。**

训练用 TD：**TD 的本质是时间差分，是上一个时刻预测和下一个时刻之间预测的修正，由于包含上一个时刻得到的奖励（事实）因此更为可信。**

两个提升表现的方法：

- **dueling network（对决网络）**：把动作价值拆成状态价值和优势两部分，**分别用两个神经网络代替这两个函数**。直观上，**对决网络可以了解到哪些状态有价值或者没价值，而无需了解每个动作对每个状态的影响**。
- **noisy net（噪声网络）**：**给神经网络的参数加高斯噪声**，**加入噪声之后的训练参数翻倍：从单一参数变成均值和方差**。**噪声 DQN 本身就带有随机性，可以鼓励探索，起到与 ε-greedy 策略相同的作用**；而且**在噪声里学习，同时能够提升模型的抵抗干扰的能力**。

---

#### policy-based learning

不再先学价值再导出策略，而是直接学**策略网络**：**输入状态 s，输出策略概率**。（**这个卷积网络取决于状态的输入维度是 1 维还是 2 维，使用不同的 encoder**。）

**目标函数。** **状态价值函数受到状态和策略两个方面的影响，在当前时刻好的状态和好的策略都会使得状态价值函数的值比较大。但是策略学习的目标函数需要排除状态的影响，所以通过对状态求期望消除这种影响。** 这是**非常常见的方法：通过条件期望消除某个变量的影响，同时 MC 可以模拟期望**。

**策略梯度定理**给出了 J(θ) 梯度的一个可从样本估计的形式（证明过程在王树森《深度强化学习》公开版 PDF 的 7.3.1 小节）。实践中，**策略梯度的近似求解：用蒙特卡洛的思想近似条件期望**。

**REINFORCE。** 最直接的策略梯度方法：**gradient ascent，朝着增加回报的方向梯度上升**，并用轨迹的观测回报 u_t 近似梯度里的 action value。

**关于是否是 on-policy 的理解：虽然参数在不断更新，但是在更新之前的 a 和 u_t 都是基于当前策略下得到的值，在更新之后会采取下一轮估计，因此只要这两者保持一致就是 on-policy。** 由此得到一个推论：**对于 on-policy 来说，每一条收集到的轨迹只会被使用一次**——策略一变就不再适用，否则就不是 on-policy 了。

**Actor-critic。** 加一个价值网络，**与 DQN 结构相同，输入状态输出动作对应的价值**。但要记住第二部分那条理解：**DQN 是最优价值函数，与特定策略无关；而价值网络得到的是给定策略下的价值，因此非最优**，所以**价值网络只能是 on-policy**。**critic 的职责实际上是根据实时奖励估计出价值（return）**，这样 actor 不必等到 episode 结束就能拿到反馈。

**with baseline（基线）。** **b 不影响策略梯度**（**与动作 A 无关即可，因为是对 A 求期望**），但能显著降低方差。由此有两个算法：

- **REINFORCE with baseline**：**Q 依旧用 MC 模拟，同时加入基线 V**。注意：**这个算法中没有 actor-critic 的成分，因为 Q 是用 MC 模拟出来的，并不是价值网络；而 V 虽然是用状态价值网络实现的，却扮演的是一个 baseline 而非 critic。**
- **A2C（advantage actor-critic）**：**智能体由策略网络 π 控制，与环境交互，并收集状态、动作、奖励。策略网络（演员）基于状态 s_t 做出动作 a_t。价值网络（评委）基于 s_t、s_{t+1}、r_t 算出 TD 误差 δ_t。策略网络（演员）依靠 δ_t 来判断自己动作的好坏，从而改进自己的演技（即参数 θ）。**

  两个版本：
  - **A2C（on-policy）**：**引入 baseline**（在 QAC 中 baseline 等于 0，通常近似成 V_π(s)）。**此算法可以平衡 exploration 和 exploitation，在 step size 的分子和分母中体现。**
  - **A2C（off-policy 版本）**：**使用 importance sampling，调节 behavior policy 和 target policy 之间的关系。**

**PPO（Proximal Policy Optimization，近端策略优化）。** 核心是 **policy gradient 从 on-policy 到 off-policy 的转变**，目的很实际：**为了重复利用收集到的数据进行训练**。路上会遇到三个问题：

1. **问题 1：不同策略采集到的 action 分布不同，因此不同 action 的重要性不同。** 解决方式：**importance sampling**。
2. **问题 2：不同策略下期望是否相同？** f(x) ~ p(x)、r(x) ~ q(x)，**通过数学可以说明这两个不同的函数和不同的期望得到的都是无偏估计**。而且**经过重要性采样之后方差能够减小，通过合理构建函数可以使得本来小概率发生但是会对期望造成比较大影响的 f(x) 的数值发生概率变大**。
3. **问题 3：如何保证策略相差不过大？** 两个办法：**KL 散度惩罚项**，或者 **clipping**。

  **理解：TRPO 也是一种函数近似方法，但是它的约束条件是外置的；相反的，在 PPO 中，函数近似直接被写在目标函数中。** 实现上有两个 actor：**actor 1 用于进行数据收集，产生轨迹；actor 2 用于进行训练，使用梯度上升更新参数。**

**TRPO（Trust Region Policy Optimization）。** 置信域**源于数值优化算法，通常用于求解非凸问题**。**在 θ_now 的邻域上，我们可以信任 L(θ | θ_now)，可以拿 L(θ | θ_now) 来替代目标函数 J(θ)。** 两个要点：**要点 1，替代函数不是在全局上都接近 J，而是在 θ_now 附近接近；要点 2，因为 L 函数是人为选择的，因此特性比较明确（例如 MC 模拟），所以用于代替 J 进行优化最大比较可行。**

循环是：**近似**（构造函数近似于目标函数）→ **最大化**（用某种数值算法求解带约束的最大化问题）→ **算法收敛**（期望达到最大）。

置信域有两种形式：**球形置信域**（简单，求解容易，但是表现平平）和 **KL 散度置信域**。

TRPO 的核心前提是**目标函数的等价形式**，以及**用 u_t，即 MC 得到的轨迹回报来近似 Q**。可调超参数有两个：**置信域的半径 Δ**，以及**求解最大化问题的数值算法的学习率**。

**Entropy Regularization（熵正则）。** **Entropy 用于衡量概率分布的不确定性。** 动机是：**不希望 agent 对于动作的输出概率被固化，因而影响探索性**——所以**希望策略网络输出的概率分布的熵不要太小，把熵作为正则项**。但要注意：**虽然熵正则能鼓励探索，但是增大决策的不确定性是有风险的：很差的动作可能也有非零的概率。**

#### 从离散控制到连续控制

上面那些带离散动作输出头的方法，遇到连续动作（力矩、转角）就失效了。有两条路。

**DPG（deterministic policy gradient）。** **基于 actor-critic**，但有一个根本改动：**和离散控制中的策略网络之间的差别是直接输出动作**（而非特定动作产生的概率），**因此从随机性策略变成了确定性策略**。价值网络的角色是：**训练过程中，价值网络用于评价策略网络，帮助策略网络训练；训练结束后不再需要"critic"，而是由"actor"单独完成表演。**

**DPG 的高估问题**同样来自两处：**最大化造成的高估**，和**自举（bootstrapping）造成偏差的传播**。两种主要解决方案：

- **采用目标网络**：**部分缓解**。
- **clipped double Q-learning**：**由于在取 TD target 的过程中有一个 min 操作，因此缓解高估问题的表现优于前者。**

还有两个改进措施：

1. **向动作中加入符合截断正态分布的噪声**——截断是为了**防止噪声过大**。
2. **减小更新策略网络和目标网络的频率。** 核心思想是：**在"critic"还不够好的时候，不要急于指导"actor"的动作。** **实验表明，应当让策略网络 µ 以及三个目标网络的更新慢于价值网络 q。传统的 actor-critic 的每一轮训练都对策略网络、价值网络、以及目标网络做一次更新。更好的方法是每一轮更新一次价值网络，但是每隔 k 轮更新一次策略网络和三个目标网络。k 是超参数，需要调。**

把 **clipped double Q-learning + 上面两个改进措施**放在一起，就是 **TD3（Twin Delayed Deep Deterministic Policy Gradient）**。

**随机高斯策略。** 另一条路：保持策略随机，但换成连续分布。

- **action space 1D**：**假设动作符合高斯分布，则分别学习高斯分布的均值和方差用于采样 a**。
- **action space nD**：引入**辅助网络**，和策略网络配合产生分布的参数。

**用策略梯度更新两个神经网络的参数**，而**策略梯度中 Q 的估计**又回到我们已经熟悉的两种方式：**REINFORCE**（蒙特卡洛回报）或 **Actor-Critic**（学出来的 critic）。

## 写在最后

把镜头拉到最远，这张地图长这样：

- **价值**回答"有多好"——对一个状态（V）、对一个状态-动作对（Q），或者在最理想的世界里（Q\*）。
- **贝尔曼方程**把这些价值递归地联系起来；有模型就直接求解（value / policy iteration），没有模型就从数据里估计（MC、TD、Q-learning）。
- **策略**既可以从价值间接导出（value-based），也可以用梯度上升直接学（policy-based），actor-critic 则把两者结合。
- 几乎所有"进阶"算法——double DQN、A2C、PPO、TD3——都是针对某一个具体病症的定向修复：高估、方差、数据复用，或者过早确定化。

遇到任何一个新算法，都不妨问自己两个问题：**它在估计什么期望？** 以及 **这个量依不依赖于收集数据的那个策略？** 光靠这两个问题，就足以把它放到这张地图上正确的位置。
